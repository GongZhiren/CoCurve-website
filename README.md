Source for the CoCurve project website (GitHub Pages):

*CoCurve: Cross-Module Co-Pruning Curvature for Training-Free Structured LLM Pruning.*
Prune the edges between units, not just the nodes — one Fisher matrix whose off-diagonal
co-pruning curvature edges are a Gram product of single-unit ablations. Paper & code coming soon.
